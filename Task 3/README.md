# 📊 Task 3 — Telco Customer Churn Analysis

## 🎯 Project Overview

This project focuses on analyzing customer churn using Microsoft Excel.

The analysis examines customer tenure, churn rate, retention rate, and identifies high-risk customer segments. The dashboard provides insights that can help businesses understand customer retention and reduce early-stage churn.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Excel Tables
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Design

## 📌 Key Analysis

The project includes analysis of:

- Customer Tenure Cohorts
- Total Customers
- Churned Customers
- Churn Rate
- Retention Rate
- Churn Rate by Tenure
- Retention Rate by Tenure
- High-Risk Customer Segments

## 🔍 Key Insights

1. **Highest Churn:** Customers with 0–12 months tenure have the highest churn rate at 48.85%.

2. **Retention Improvement:** Retention increases significantly as customer tenure increases.

3. **High-Risk Segment:** New customers in the 0–12 month tenure segment represent the highest-risk group.

4. **Long-Term Retention:** Customers with 61–72 months tenure have the highest retention rate at 93.87%.

5. **Retention Strategy:** Businesses should focus on early onboarding, customer support, and engagement to reduce early customer churn.
